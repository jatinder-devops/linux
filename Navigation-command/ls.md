# ls
### list file
**ls cmd** is used to list all file and directory in the linux.

### To display list of items in directory 
```
ls
```
### To display list of item of specified path 
```
ls /path/to/directory/
```
 ###  To display list with all details
 ```
ls -l
 ```
### To display list in human readable 
```
ls -h
```
### To display list of items according to time
```
ls -t
```
### To display list of item in reverse order 
```
ls -r
```

### To display list file in single line 
```
ls -1
```
###  To display list of item  parent directory of current directory.
```
ls ..
```
