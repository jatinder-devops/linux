# #rm 
### ***rm*** stand for remove(delete).this command is used for delete file and directories.
### basic syntax
```
rm <option> <filename>
```
## use case of command
### To remove a file or directory
```
rm <file-name>
```
### To remove multiple file or directories.
```
rm -r <dir1 dir2>
rm  <file-name file-name>
```
### To take the user confirmation before deleting any file or directory
```
rm -i <file-name>
```
### To get output of what is being done
```
rm -v <file-name>
```
### To delete a directory and its content recursively 
```
rm -r <file-name/file>
```
### To delete an item  forcefully
```
rm -f <file-name>
```
