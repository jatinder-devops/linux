# #cat
***cat*** The name cat comes from the word concatenate. Concatenation means joining multiple items together. The primary purpose of the cat command is to read files, display their contents, and combine multiple files.
### The basic syntax is:
```
cat [OPTION] [file]
```
### To display the content of file 
```
  cat <filename>
```

### To diplay content of file using its path
```
  cat /path/to/filename
```

### To display the content of multiple files in linux
```
  cat <file1> <file2> <file3>
```

### To add content in file.
```
  cat >> <filename>
```
  Ctrl + d -> Save and Exit

### To merge the content of files 
```
  cat <file1> <file2> > <newfile>
```
