# #touch
***touch*** is used for creating empty file. 
We need to specify the file extension to define the type of file like  .html .py .sh, etc 
without extension touch by default  create txt file.
### Here are some popular extensions 


 
| .html     | html file Hyper Text Markup Language  | 
| :-------- | :------------------------------------ | 
| .css      | css file cascading style sheet        |
| .sh       | Shell script                          | 
| .py       |  Python                               |
