# File System 
In computing, a file system or file system is used to control how data is stored and retrieved. Without a file system,
information placed in a storage medium would be one large body of data with no way to tell where one piece of information stops and the next begins.
By separating the data into pieces and giving each piece a name, the information is easily isolated and identified
