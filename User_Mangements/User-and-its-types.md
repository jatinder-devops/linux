# What do we mean by user in Linux ?
- user is a system entity that can login and access the system. Each user has its own identity, permissions, and access privillages.
- The Best practice of the user in Linux each user has their own individual user  rather than sharing single user. Having separate user account provide better accountability, security and and access control which makes easier to track which user  performed a particular action or made a specific  change to the system.
## Types of user
- ***Root-User***:  (superuser) It is super user it has all admin privileges. It doesn't need any password or confirmation to changes in the system.
- ***Regular***:    (normal user) Limited access user, can read files in all directories but have write access in limited directories.
- ***System user***: User create by System for running services.
- ***Sudo user***:   regular with temporary admin privileges.
- ***Guest User***:  Temporary user with minimal privileges.
